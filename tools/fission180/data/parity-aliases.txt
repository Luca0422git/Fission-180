# Deliberate naming differences between Fusion's command names (fusion-menus.txt) and
# Fission 180's menu labels, read by tools/fission180/parity.py.
#
#   Fusion name = Fission 180 name
#   Fusion name = Fission 180 name | another Fission 180 name      (the first one found counts)
#   AREA > Panel > Fusion name = Fission 180 name               (only for that place: the left
#                                                             side is the end of the path)
#
# Case, spaces round "/" and a trailing "..." do not matter. Only map a name when Fission 180's
# entry really is that command (an honest checklist beats a high number); a unit test checks
# that every line here still matches a Fusion name and a Fission 180 label.
