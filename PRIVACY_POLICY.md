# Fission 180 Privacy Policy

Fission 180 does not collect, transmit, share or use any personal data. There is no telemetry and there are no
accounts. The only thing Fission 180 sends on its own is the optional update check (one request to
`api.github.com`, switchable in Preferences).

The full, plain-language details (AI features, cloud places, crash logs, Report a Problem) are in
[docs/fission180/privacy.md](docs/fission180/privacy.md).

Fission 180 is based on [FreeCAD](README.FreeCAD.md). FreeCAD's own caveats (loading remote files, installing
add-ons, files that can contain your folder names) apply to the FreeCAD parts that Fission 180 still contains.
