# Contributing to Fission 180

Fission 180 is a beta and one person directs it, so the process is simple:

- **Found a bug?** Open an issue with the "Bug report" form (or use *Help > Report a Problem* in Fission 180, which
  fills the form for you).
- **Have an idea or a question?** Use GitHub Discussions.
- **Want to change code?** Please open an issue or discussion first. Work happens on the `develop` branch; read
  [docs/fission180/README.md](docs/fission180/README.md) for how the project is laid out and tested.
- New Fission 180 code goes in `src/Mod/Fission180/`. Changes to FreeCAD's own files need a `FISSION180:` comment and a
  row in [docs/fission180/core-patches.md](docs/fission180/core-patches.md).

Fission 180 is licensed LGPL-2.1-or-later, like FreeCAD, and contributions are accepted under that license.
